# 🎬 videopril — AI Video Highlight Clipper

Локальное веб-приложение для автоматического поиска интересных моментов в видео с помощью ИИ и моментальной нарезки клипов.

## 🚀 Быстрый старт

Просто запустите:
```
start.bat
```
Приложение откроется в браузере по адресу **http://localhost:5173**

---

## ⚙️ Ручной запуск

### Backend (FastAPI)
```bash
cd backend
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### Frontend (Vite)
```bash
cd frontend
npm run dev
```

## ⏯ Управление Whisper

После запуска локального распознавания появляется отдельная панель операции:

- **Пауза** приостанавливает обработку после текущего сегмента речи;
- **Продолжить** снимает паузу;
- **Остановить с сохранением прогресса** освобождает процессор, но оставляет
  распознанный текст и последний таймкод в памяти backend;
- после остановки кнопка **Продолжить** запускает Whisper с сохранённого места;
- частичный текст, процент и примерное оставшееся время отображаются прямо в
  панели.

Можно обновить страницу браузера: пока backend продолжает работать, интерфейс
найдёт текущую операцию и восстановит её состояние. Если закрыть окно backend,
перезапустить `start.bat` или выключить компьютер, незавершённый прогресс
Whisper исчезнет. Полностью завершённые транскрипты сохраняются как раньше.

## 🧠 Режимы анализа

### С Gemini API Key (рекомендуется)
- Нажмите ⚙️ **Настройки** в приложении
- Вставьте ваш бесплатный ключ с [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
- ИИ анализирует кадры видео по вашему текстовому запросу (смысловой поиск)

### Без API Key (локальный режим)
- Автоматически обнаруживает смены сцен и аудио-пики через FFmpeg
- Работает полностью офлайн
