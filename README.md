# 🎬 videopril — AI Video Highlight Clipper

Локальное веб-приложение для автоматического поиска интересных моментов в видео с помощью ИИ и моментальной нарезки клипов.

## 🚀 Быстрый старт

Просто запустите:
```
start.bat
```
Приложение откроется в браузере по адресу **http://localhost:5173**

---

## ⚙️ Ручной запуск

### Backend (FastAPI)
```bash
cd backend
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### Frontend (Vite)
```bash
cd frontend
npm run dev
```

## ⏯ Управление Whisper

После запуска локального распознавания появляется отдельная панель операции:

- **Пауза** приостанавливает обработку после текущего сегмента речи;
- **Продолжить** снимает паузу;
- **Остановить с сохранением прогресса** освобождает процессор, но оставляет
  распознанный текст и последний таймкод на диске;
- после остановки кнопка **Продолжить** запускает Whisper с сохранённого места;
- частичный текст, процент и примерное оставшееся время отображаются прямо в
  панели.

Можно обновить страницу, закрыть backend или перезагрузить компьютер: последний
безопасный checkpoint сохраняется в проекте. После следующего запуска операция
появится в состоянии «Остановлено» и **не стартует сама** — нажмите
**Продолжить**, когда будете готовы снова запустить Whisper. Кнопка
**Начать заново** удаляет старый прогресс только после подтверждения и запускает
распознавание с начала.

## 📂 Сохранённые проекты

Проекты находятся только внутри папки приложения на диске `E:`:
`E:\ArkaimVPNproject\data\projects\<project-id>`. В папке проекта хранятся
метаданные и настройки редактора, незавершённый `checkpoint.json` либо готовый
`transcript.json`. Запись выполняется атомарно: сначала создаётся временный файл,
затем он заменяет предыдущую версию, поэтому внезапное закрытие не должно
оставлять наполовину записанный JSON.

На стартовом экране показаны до 20 последних проектов. Это только ограничение
списка: старые папки и результаты с диска **не удаляются**. Нажмите **Открыть**,
чтобы вернуть видео, текст, найденные моменты и настройки редактора. Для
остановленной транскрипции используйте **Продолжить**; для полного повторного
распознавания — **Начать заново**.

Сообщение «Исходный файл не найден» означает, что видео было перемещено или
удалено. Верните файл по прежнему пути и повторите продолжение — checkpoint не
стирается. Сообщение о повреждённом/нечитаемом checkpoint означает, что этот
прогресс нельзя безопасно продолжить; проект и остальные сохранённые данные при
этом не удаляются, можно запустить распознавание заново.


## 🎛 Независимый редактор клипов

У каждого найденного момента есть кнопка **Править**. Она открывает
неразрушающий редактор: исходное видео не изменяется, а настройки сохраняются
только внутри выбранного клипа.

1. Расширьте начало или конец момента ползунками либо точными числовыми полями.
2. Выберите **Основное видео**, измените область исходника, размер и положение
   изображения на выходном кадре.
3. Сначала загрузите видео-баннер или рекламный ролик в блоке **Реклама**, затем
   добавьте его в редакторе. Слой можно перемещать, независимо растягивать по
   ширине и высоте и ограничивать временем показа.
4. Для рекламы выберите **В свободной области** либо **Отдельная вставка**.
5. Нажмите **Сохранить клип** и экспортируйте один клип, выбранные клипы или
   общий ролик. У готового отдельного клипа доступно действие
   **Редактировать снова**.

Кнопка **Сбросить поля** возвращает исходную геометрию внутри редактора.
Кнопка **Обычный экспорт без компоновки** полностью удаляет индивидуальные
настройки этого клипа и возвращает совместимый старый режим экспорта. Глобальные
настройки баннера и рекламы действуют только на такие обычные клипы; сохранённая
индивидуальная композиция всегда имеет приоритет.

### Проверка оператором

Codex не запускал тесты, frontend-сборку и FFmpeg-рендер по указанию оператора.
Для проверки вручную используйте локальные runtime и кэши только на диске `E:`:

```powershell
$env:TEMP = "E:\ArkaimVPNproject\.tmp"
$env:TMP = "E:\ArkaimVPNproject\.tmp"
$env:TMPDIR = "E:\ArkaimVPNproject\.tmp"
$env:PIP_CACHE_DIR = "E:\ArkaimVPNproject\.pip-cache"
$env:npm_config_cache = "E:\ArkaimVPNproject\.npm-cache"
$env:HF_HOME = "E:\ArkaimVPNproject\models"

& "E:\ArkaimVPNproject\runtime\python\python.exe" -m unittest discover -s "E:\ArkaimVPNproject\backend\tests" -v
$frontendTests = Get-ChildItem "E:\ArkaimVPNproject\frontend\src" -Recurse -Filter "*.test.js" | ForEach-Object FullName
& "E:\ArkaimVPNproject\runtime\node\node.exe" --test $frontendTests
& "E:\ArkaimVPNproject\runtime\corepack\v1\pnpm\12.14.0\pnpm-native.exe" --dir "E:\ArkaimVPNproject\frontend" run build
```

После автоматических проверок запустите `start.bat`, создайте два клипа из
одного исходника с разной геометрией, добавьте короткий баннер и рекламу без
звука, экспортируйте отдельно и склейкой и визуально сравните результат с
предпросмотром.

## 🧠 Режимы анализа

### С Gemini API Key (рекомендуется)
- Нажмите ⚙️ **Настройки** в приложении
- Вставьте ваш бесплатный ключ с [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
- ИИ анализирует кадры видео по вашему текстовому запросу (смысловой поиск)

### Без API Key (локальный режим)
- Автоматически обнаруживает смены сцен и аудио-пики через FFmpeg
- Работает полностью офлайн
