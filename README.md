# 🛡️ Аркаим Studio — AI Video Highlight Clipper

Локальное веб-приложение для автоматического поиска интересных моментов в видео с помощью ИИ и моментальной нарезки клипов.

## 🚀 Быстрый старт

Репозиторий не содержит API-ключей, пользовательских видео, моделей и бинарных
runtime. Для запуска нужны Python 3.12, Node.js 22+ и FFmpeg в `PATH`.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r backend\requirements.txt
npm --prefix frontend ci

# Терминал 1
python -m uvicorn main:app --app-dir backend --host 127.0.0.1 --port 8000

# Терминал 2
npm --prefix frontend run dev -- --host 127.0.0.1
```

Откройте **http://127.0.0.1:5173/**. Локальные portable-runtime автора и
скрипты `start.bat` рассчитаны на его E-drive сборку и в публичный репозиторий
не входят как бинарные зависимости.

## ⚙️ Ручной запуск

### Backend (FastAPI)
```cmd
backend\start_backend.bat
```

### Frontend (Vite)
```cmd
frontend\start_frontend.bat
```

Оба сервера слушают только локальный адрес `127.0.0.1`; приложение не открывает
административные API для других устройств в локальной сети.

## ⏯ Управление Whisper

После запуска локального распознавания появляется отдельная панель операции:

- **Пауза** приостанавливает обработку после текущего сегмента речи;
- **Продолжить** снимает паузу;
- **Остановить с сохранением прогресса** освобождает процессор, но оставляет
  распознанный текст и последний таймкод на диске;
- после остановки кнопка **Продолжить** запускает Whisper с сохранённого места;
- частичный текст, процент и примерное оставшееся время отображаются прямо в
  панели.

Можно обновить страницу, закрыть backend или перезагрузить компьютер: последний
безопасный checkpoint сохраняется в проекте. После следующего запуска операция
появится в состоянии «Остановлено» и **не стартует сама** — нажмите
**Продолжить**, когда будете готовы снова запустить Whisper. Кнопка
**Начать заново** удаляет старый прогресс только после подтверждения и запускает
распознавание с начала.

## 📂 Сохранённые проекты

Проекты находятся внутри папки приложения:
`<repo>\data\projects\<project-id>`. В папке проекта хранятся
метаданные и настройки редактора, незавершённый `checkpoint.json` либо готовый
`transcript.json`. Запись выполняется атомарно: сначала создаётся временный файл,
затем он заменяет предыдущую версию, поэтому внезапное закрытие не должно
оставлять наполовину записанный JSON.

На стартовом экране показаны до 20 последних проектов. Это только ограничение
списка: старые папки и результаты с диска **не удаляются**. Нажмите **Открыть**,
чтобы вернуть видео, текст, найденные моменты и настройки редактора. Для
остановленной транскрипции используйте **Продолжить**; для полного повторного
распознавания — **Начать заново**.

Сообщение «Исходный файл не найден» означает, что видео было перемещено или
удалено. Верните файл по прежнему пути и повторите продолжение — checkpoint не
стирается. Сообщение о повреждённом/нечитаемом checkpoint означает, что этот
прогресс нельзя безопасно продолжить; проект и остальные сохранённые данные при
этом не удаляются, можно запустить распознавание заново.

## 🧠 Режимы анализа

### С Gemini API Key (рекомендуется)
- Нажмите ⚙️ **Настройки** в приложении
- Вставьте ваш бесплатный ключ с [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
- ИИ анализирует кадры видео по вашему текстовому запросу (смысловой поиск)

### Без API Key (локальный режим)
- Автоматически обнаруживает смены сцен и аудио-пики через FFmpeg
- Работает полностью офлайн
